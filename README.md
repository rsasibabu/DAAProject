Sorting Visualizer

An interactive web-based Sorting Visualizer that demonstrates how different sorting algorithms work through animations and step-by-step explanations.

Features
- Visualizes 7 sorting algorithms.
- Custom array input (up to 20 integers).
- Adjustable animation speed with Start, Pause, and Reset controls.
- Displays time and space complexity.
- Step-by-step sorting explanations.

Technologies Used :
HTML, CSS, JavaScript
